DXZ T4LH4 WEBSITE PACKAGE

Files:
- index.html: responsive player profile website
- assets/dxz-t4lh4-player.jpg: profile photo
- robots.txt and sitemap.xml: search engine helper files

IMPORTANT:
This package is a ready-to-publish static website, but it is NOT online yet.
Replace YOUR-DOMAIN.example in robots.txt and sitemap.xml after you have a real domain.

Suggested publishing:
1. Create a GitHub account and a new public repository named dxz-t4lh4.github.io
2. Upload index.html, robots.txt, sitemap.xml and the assets folder to the repository root.
3. In repository Settings > Pages, enable deployment from the main branch.
4. Your site will appear at https://YOUR-USERNAME.github.io (replace YOUR-USERNAME).
5. After it is live, add the site in Google Search Console and request indexing.

Before publishing:
- Add only verified tournament results and official social links.
- Do not add home address, phone number, school, personal email, passwords, or other private details.
- Use only team/roster claims that are accurate and authorized.
